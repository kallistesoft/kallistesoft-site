About Kallistesoft

Québec · Alberta, Canada

Kallistesoft is a Québec software studio (9536-3529 Québec inc.), run from Cochrane, Alberta. Behind it is Jef Ottavi, a senior developer specialising in Android (Kotlin) and iOS mobile apps, with more than ten years of experience designing and delivering reliable, high-scale applications, both in large organizations and on his own products.

Background

Over ten years designing and delivering reliable, high-scale mobile applications in finance, insurance and enterprise. Specialities: Android architecture (Kotlin, Jetpack Compose), Kotlin Multiplatform, clean architectures (MVVM, MVI), CI/CD, code review and team mentoring. More recently, integrating AI-assisted development (Claude, Copilot, automated code review) into engineering practice.

  • Today: contract Android developer, alongside Kallistesoft, in finance and insurance.
  • Android / iOS / KMP Tech Lead, large financial institution (2022-2025): rebuilt the main app in Kotlin, coroutines, Flow and Jetpack Compose, then led the Android, iOS and Kotlin Multiplatform mobile team.
  • Android Developer, large insurance group (2021-2022): insurance app with 100,000+ users, MVI architecture, Jetpack Compose, Kotlin Flow, business logic shared with Kotlin Multiplatform.
  • Native Mobile Developer, mobile solutions vendor (2021): Android (Kotlin, Java) and iOS (Objective-C), new features, bug fixes and code review.
  • Android Developer, industrial device maker (2020), France: industrial apps and SDK for rugged devices: NFC and RFID reading, biometrics, REST API sync, Android 8 to 10 support without Google services.
  • Android and JavaFX Developer, software SME (2018-2020), France: Android apps and a Cobol to JavaFX migration.
  • Certifications: Professional Scrum Master I (Scrum.org, 2020) and Secure Coding for Android / Kotlin, level 1 (Secure Code Warrior, 2021).
  • Community: jury member of the AMC at École de technologie supérieure (Montréal), judging mobile engineering projects.
  • Profile: LinkedIn.

What we do
