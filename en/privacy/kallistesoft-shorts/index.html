KallisteSoft Shorts — Privacy Policy

Last updated: November 13, 2026

KallisteSoft Shorts is an internal tool of Kallistesoft (9536-3529 Québec inc.). It runs only on our own computer and uploads short gameplay videos of our games to our own YouTube channel (KallisteSoft). It is not offered to the public and no one outside Kallistesoft signs in to it.

1. Use of YouTube API Services

The tool uses the YouTube API Services (YouTube Data API v3) to upload videos and set their title, description, tags and publication time. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's processing of data is described in the Google Privacy Policy.

2. What data the tool accesses

The tool asks for one permission only: youtube.upload, which lets it upload videos to the channel of the account that signs in. It does not read, list or change any other YouTube data: no comments, no subscribers, no watch history, no analytics, no other user's data.

3. What is stored, and where

  • Sign-in token: the OAuth token Google returns is stored in one file on our computer, readable only by our user account. It is never sent anywhere except to Google to authorize uploads.
  • Upload log: for each upload, the tool records the YouTube video ID, title and scheduled publication time in a file in our source repository, so a video is never uploaded twice.
  • The videos themselves are made by us from our own games. No personal information about anyone is collected, stored or shared.

We do not share any data obtained through the YouTube API Services with third parties, and we use no cookies or analytics in the tool.

4. Revoking access and deleting data

Access can be revoked at any time from the Google Account's security settings: Third-party apps & services (the app is listed as "KallisteSoft Shorts"). Revoking makes the stored token useless; we then delete the token file. The upload log only holds IDs of videos published on our own channel; any entry is deleted on request, and within 30 days if access is revoked.

5. Contact

Questions or requests: contact@kallistesoft.ca. Kallistesoft, 9536-3529 Québec inc., 529 4th Avenue, Saint-Jean-sur-Richelieu, Quebec J2X 1X3, Canada. See also our general privacy policy and the tool's terms of use.

6. Changes

We will update this page if the tool changes, for example if it ever needs another permission. The date at the top shows the latest revision.
